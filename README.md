## Hi there 👋

I'm Logan Cadman. I'm a Linux Systems Engineer at Visa, where I work on infrastructure reliability for a compute team that runs around the clock. I finished my M.S. in Computer Science at Colorado State University a little over a year ago, and I've been doing this full-time since.

My path into tech wasn't the typical route. I started as an automotive technician working on VWs and Audis, learning real hands-on problem solving long before I touched Linux or wrote code. That background still shapes how I think today: keep things simple, reliable, and easy to understand. If it can break at 2am, it probably will, so build it like you'll be the one getting paged.

Before Visa, I spent about five years as a sysadmin and researcher at CSU, where I managed hundreds of Linux systems, automated anything repetitive, and worked on networking, security, and infrastructure projects. I spent a lot of time researching internet transmission errors, building adaptive honeypots, and writing tools in C and Python for system-level debugging. A couple of papers came out of that work, including one at FSE 2025.

These days my job is a mix of keeping things running and making sure fewer things need to be kept running. The part I enjoy most is the automation side, and lately that's meant building LLM-powered tooling to help with incident response. On the side, I've been building a few things for myself. BudgetSimpli is a local-first budget tracker (Next.js + SQLite) with an AI paycheck allocation engine that looks at my bills, debts, and goals and tells me exactly how to split each check. I'm also tinkering with a habit tracker app in SwiftUI and a diagnostic tool for VAG fault codes that combines my old job with my new one.
